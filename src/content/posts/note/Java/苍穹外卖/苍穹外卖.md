    JWT的解析在Inceptor层已经实现，但问题是：我们应该如何将id从Inceptor层传递到serviceimpl层呢?  ———  **ThreadLocal技术**

    - ThreadLocal：线程的一个局部变量，为每个线程提供了单独的一份存储空间，具有**线程隔离的效果**。只有在线程内才能获取到对应的值，线程外不能访问

    - 客户端发起的每一次请求Tomcat都会为其分配一个单独的线程，也就是说，**在一次请求中，线程会贯穿始终**（如一次insert操作，线程会先后经过Inceptor  Controller  Service  Mapper）如此一来我们可以将**要传递的数据放在TreadLocal里面进行传递**

    ![image-20260705142449630](https://xin-note-pic.oss-cn-hangzhou.aliyuncs.com/java/sky-take-out/image-20260705142449630.png)

## 6.Redis及店铺营业状态设计

### 01.Redis入门

- Redis是一个**基于内存**的key-value结构数据库

  读写性能高，适合存储热点数据（热点商品、资讯、新闻）这种短时间内会有大量用户访问的数据。

- 在redis的配置文件中修改密码后在使用redis-cli使用redis时需要用**-a**指定密码

### 02.Redis中五种常用的数据类型

1. 字符串string

   > Redis中最简单的数据类型

2. 哈希hash

   > 以键值对的方式存储，类似Java中的HashMap
   >
   > 可以用于存储一些对象

3. 列表list

   > 顺序插入排序，可以有重复元素，类似Java中的LinkedList

4. 集合set

   > 无序集合，无重复元素，类似Java中的HashSet
   >
   > 可以用来做运算，计算不同集合间的交集、并集、差集等

5. 有序集合sorted set/zset

   > 集合中每个元素关联一个分数（score），根据分数升序排序，无重复元素

### 03.Redis中的常用命令

#### 001.字符串操作命令

1. SET key value：设置指定key的值

   > 如：set name jack

2. GET key：获取指定key的值

   > 如：get name     —>返回jack

3. SETEX key seconds value：设置指定key的值，并将key的过期时间设置为seconds秒  （短信验证码）

   > 如：setex code 30 123

4. SETNX key value：只有key不存在时设置key的值

   > 如：setnx code 1234    — 若key存在返回0

#### 002.哈希操作常用命令

  ![image-20260707083958854](https://xin-note-pic.oss-cn-hangzhou.aliyuncs.com/java/sky-take-out/image-20260707083958854.png) 

1. HSET key field value：将哈希表中的字段field设为value

   > 如：hset 100 name zhangsan

2. HGET key field：获取存储在哈希表中指定字段的值

   > 如：hdel 100 name

   > 如：hkeys 100  —>返回 name  age

5. HVALS key：获取哈希表中所有值

   > 如：hvals 100 —>返回 zhangsan  18

#### 003.列表操作命令

- 结构图

  ![image-20260707084422257](https://xin-note-pic.oss-cn-hangzhou.aliyuncs.com/java/sky-take-out/image-20260707084422257.png)

1. LPUSH  key  value1 value2 value3  … （L代表Left表示从左侧插入）

   > 如：lpush mylist a b c  d e f g  —  key不存在时自动创建  相当于头插法，插入后a在最右侧

2. LRANGE key start stop：获取指定范围内的元素  **（左闭右闭）**

3. RPOP key：移除并获取列表最右侧的元素（R代表Right）

4. LLEN key：获取列表长度

   > 如：llen mylist

2. SMEMVERS key：返回集合中所有成员

3. SCARD key：返回集合的成员数

   > 如：scard set1  —  返回4

4. SINTER key1 key2…：返回给定所有集合的交集

   > 如：sinter set1  set2  —  返回b c d

5. SUNION key1 key2…：返回给定所有集合的并集

   > 如：sunion  set1  set2  — 返回a b c d e

6. SREM key member1 member2…：删除集合中成员

   > 如：srem set1 a b   — 删除set1中的a b

#### 05.有序集合操作命令

- 有序集合也是String类型的集合，不允许有重复的元素，每个元素都会关联一个double类型的分数用于排序

  ![image-20260707085837440](https://xin-note-pic.oss-cn-hangzhou.aliyuncs.com/java/sky-take-out/image-20260707085837440.png) 

1. ZADD key score1 member1 score2 member2…:向有序集合中添加成员

   > 如：zadd set1 3.0 a 2.0 b 1.0 c

2. ZRANGE  key  start stop[WITHSCORES]：返回给定区间内的成员，可加上WITHSCORES将分数一同返回

   > 如：zrange set1 0 -1  — 返回a  b  c（分数高的在前面）

3. ZINCREBY key increment member：对某一成员的成绩加上increment

   > 如：zincreby set1 10.0  c  — 这样一来c的分数就是11.0了  排到最前面

4. ZREM key member1 member2…：删除成员

   > 如：zrem set1 c b

#### 06.通用命令

- 不分数据类型的，都可以使用的命令

1. KEYS pattern：查找所有符合给定模式（pattern）的key

   > 如：keys * / keys set*     *即通配符

2. EXISTS key：检查给定key是否存在

   > 如：exists  set1     存在返回1  不存在返回0

3. TYPE key：返回key所存储的值的类型

   > 如：type  set1   — 返回set类型

4. DEL key：删除给定key

   > 如：del set1

       ![image-20260707191045626](https://xin-note-pic.oss-cn-hangzhou.aliyuncs.com/java/sky-take-out/image-20260707191045626.png)

       tip：若想要批量删除应使用下面的语句

       @CacheEvit(cacheNames=“”,**allEntries=true**)
